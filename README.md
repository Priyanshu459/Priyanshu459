### 👨‍💻 About Me

- 🧠 **LLM Training & Fine-Tuning:** Hands-on experience preparing datasets, fine-tuning custom models (SFT, DPO, model soups), running evaluation benchmarks, and quantizing models to GGUF (Q8_0) for local and mobile inference via Ollama.
- 📱 **Mobile Development:** Built the **Moonlight** visual social app for Android using **Flutter** and **Dart**, backed by **Supabase** with reactive state management and Row Level Security (RLS).
- 🌐 **Web Development:** Built and shipped the **Moonlight Web** platform using **Next.js 14**, **TypeScript**, and **Tailwind CSS**, deployed globally on **Cloudflare Pages**.
- 🛠️ **Open Source & Utilities:** Active repository contributions spanning TypeScript (`Sick_Pdf`), Python automation tools, and smart contract experiments.
